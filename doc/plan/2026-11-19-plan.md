## ねらい

国内で今買える部品だけで、**Sim2Real (S2R) と Real2Sim (R2S) の輪を 1 周回す**。

- 実機: IMU を載せた XIAO（候補は調査で決める）＋ 2 輪差動の小さな車体。
- 観測は IMU だけ（エンコーダー無しで始める）。課題は「ヨー角速度を指令どおりにする」。
- S2R: sim で制御器のゲインを決め、パラメータをばらつかせて（domain randomization）確かめてから実機へ。
- R2S: 実機のステップ応答のログから、モーターの時定数・ゲイン・ジャイロのバイアスを同定して sim を直す。
- この PC は GPU 無し・RAM 7 GiB の WSL2 なので、sim は numpy（必須）と MuJoCo（任意）。Isaac Sim は手引きだけ。

## 境界

## 決まったこと

- **ボード**: 第一候補は XIAO nRF52840 Sense（IMU は LSM6DS3TR-C、技適あり）。次点は XIAO MG24 Sense、在庫の保険は XIAO nRF54L15 Sense。根拠は [../research/2026-11-19-hardware.md](../research/2026-11-19-hardware.md)。
- **モータードライバー**: DRV8835（秋月 AE-DRV8835-S、MODE=GND の IN/IN）。DRV8833 は秋月で見つからなかった。
- **BOM**（JST 13:35〜13:40 取得、税込・送料別）: (A) 最小 3,155 円、(B) 車体込み 7,851 円 ＋ 単3 電池 4 本。取得時、nRF52840 Sense は秋月の残り 9 個・スイッチサイエンスは売り切れ。
- **sim の構成**: [ADR-0001](../adr/0001-sim-stack.md)。numpy 必須、MuJoCo 4.0.1 任意、Isaac Sim は手引きだけ。
- **観測は IMU のジャイロだけ**。エンコーダー無しで始める。
- **同定の実験の形**（S008）: 静止 1 s のあと、旋回の指令 u = +0.2, −0.2, +0.35, −0.35, +0.5, −0.5 を各 1 s、間に 0 を 1 s（計 13 s）。符号を交互にして USB ケーブルのねじれを防ぐ。sim・MuJoCo・実機のログ取りで同じ形。
- **安全ゲートの上限**（S008）: `SafetyGate` の duty 上限を、スケッチの `DUTY_MAX` と同じ 0.6 に。
- **監査の結果**（S016）: 文書の事実の主張 63 件のうち、裏づけあり 46、取り直せず 5、二次的 5、断り書きつきの根拠なし 2、誤り 5。誤りは S019・S022 が直している。
- **remote と CI**: まだ無い。GitHub か GitLab は発注者が後で用意する。CI と push はその知らせを待つ（13:36 頃の指示）。

## 次にやること（優先順）

各セッションの作業記録の「確かめていないこと」と、展望（[2026-11-19-outlook.md](2026-11-19-outlook.md)）の推薦から拾った。

1. **実機が届いたら、この順で確かめる**（[09 章](../textbook/09-safety.md) を先に読む。車輪は浮かせる）。
   1. XIAO 単体: スケッチを書き込み、USB シリアルで IMU の行が 100 Hz で来るか。IMU の電源ピンと I2C アドレス。
   2. 静止ログ: ジャイロのバイアスと雑音。温度が落ち着くまでの時間。
   3. 軸の向き: 手で回してヨー角速度の符号が sim と同じか（[../protocol.md](../protocol.md)）。
   4. ウォッチドッグ: USB を抜く・送信を止めると 200 ms でモーターが止まるか。
   5. PWM と DRV8835: duty と回転の向き、不感帯。duty 上限 0.6 が効くか。
   6. 同定ログ（`python -m physlearn.link` の同定の実験）を取り、`physlearn sysid` が読めるか。
   7. 同定したパラメータで決めたゲインを実機に戻し、仕様（整定・行き過ぎ・定常偏差）を満たすか。
2. **remote と CI**: 発注者から GitHub / GitLab の知らせが来たら、push と `uv run pytest` の CI を足す。
3. **MG24 Sense のコンパイル**: Silicon Labs のコア（約 620 MB）を、/tmp（tmpfs）ではない場所に入れて試す。
4. **在庫の再確認**: nRF52840 Sense と Robo Base キット（ページを直接読めていない）、電池・コンデンサの価格。
5. **sim の確かめ**: `SPREAD` の幅が実機のばらつきに見合うか、seed 0 以外の loop-demo、numpy と MuJoCo の sim の比較、MuJoCo の描画が WSL2 で動くか。
6. **エンコーダー**: 実機の最初の 1 週間が済んだら、1〜3 か月の筋の中で**最初に**足す（展望の推薦）。gz と独立にヨー角速度が出るので、評価の真値の代わりになり、左右別の K・τ も測れる（[10 章](../textbook/10-next-steps.md)）。
7. **S2R の幅を実測から決める**: `randomize.SPREAD` は当て推量のまま。複数のログから幅を出す道具を足す（展望の弱点 2）。
8. **Isaac Sim**: GPU のある環境が用意できたら 90 章の手順を初めて実行する（いまは未実行）。
