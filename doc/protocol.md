# PC ⇔ XIAO シリアルの取り決め

実装: `firmware/xiao_imu_drive/xiao_imu_drive.ino`（MCU 側）、`src/physlearn/link.py`（PC 側）。
状態: nRF52840 Sense 向けにコンパイルは通った（S009 で DRV8835 に合わせたあとも再確認）。MG24 Sense は未コンパイル。**実機ではまだ試していない**。

## 線のこと

- USB シリアル（XIAO nRF52840 は USB CDC。MG24 の USB の仕組みは未確認）。115200 baud（CDC では実際の速さに効かない）。
- 1 行 = 1 メッセージ。ASCII、区切りは空白 1 個、行末は `\n`（`\r\n` も受ける）。
- 端末（`screen /dev/ttyACM0 115200`、`picocom` など）で打って読めるように、全部テキスト。

## PC → MCU

| 行 | 意味 |
|---|---|
| `M <left> <right>` | 左右モーターの duty。-1..1、前進が正。例 `M 0.300 -0.300` |
| `S` | 停止（両輪 duty 0） |

- MCU は `|duty|` を `DUTY_MAX`（既定 0.6）で切る。PC 側も -1..1 に丸めて送る（|duty| > 1 は ±1 に丸め、最終的な上限は MCU の `DUTY_MAX`）。NaN・無限大は送らず `ValueError` にする（`SerialPlant.step` はそのとき `S` を送る）。MCU も `isfinite` でない行は捨てる。
- **ウォッチドッグ**: 正しい `M` か `S` が 200 ms 来ないと MCU は停止する。走らせ続けたいときは同じ `M` を 200 ms より短い間隔で送り直す（`SerialPlant` は 50 ms ごと）。
- 起動直後は停止している。
- duty からピンへ（DRV8835、MODE=GND の IN/IN、fast decay）: duty > 0 は IN1 に PWM・IN2 = 0（正転）、duty < 0 は IN1 = 0・IN2 に PWM（逆転）、0 は両方 0（空転）。ブレーキ (1・1) は使わない。PWM は 8 bit・約 62.7 kHz（nRF52 コアの既定）。

## MCU → PC

| 行 | 意味 |
|---|---|
| `I <t_ms> <ax> <ay> <az> <gx> <gy> <gz>` | IMU の 1 サンプル。100 Hz |
| `# ...` | 人向けの知らせ（エラーなど）。PC は読み捨てる |

- `t_ms`: MCU の起動からのミリ秒（整数、`millis()`）。約 49 日で 0 に戻る。
- `ax ay az`: 加速度 m/s^2（小数 3 桁）。静止して水平なら `az ≈ +9.81`。
- `gx gy gz`: 角速度 rad/s（小数 4 桁）。右手系、軸まわりに反時計回りが正。
- 座標は **基板（IMU チップ）の座標**。機体座標（x 前・y 左・z 上）への付け替えは PC 側の `--axes`（`SerialPlant(axes=...)`）で行う。例: 基板を z まわりに 90° 回して付けたら `-y,x,z`。鏡映（右手系でなくなる指定）は受け付けない。
- 加速度・角速度の換算: ライブラリの g・deg/s をそれぞれ 9.80665 倍・π/180 倍して送る。測定範囲はライブラリ既定（±16 g・±2000 deg/s）。
- IMU が見つからないと `I` の代わりに `# ERR imu not found` を流す（モーター指令は受ける）。

例（静止・水平）:

```
I 52310 0.012 -0.034 9.806 0.0011 -0.0007 0.0002
I 52320 0.010 -0.031 9.809 0.0009 -0.0006 0.0003
```

## エラーの扱い

- MCU: 解釈できない行・47 文字を超える行は捨てて `# ERR bad line` / `# ERR line too long` を返す。捨てた行はウォッチドッグを延長しない（＝壊れた行が続けば止まる）。
- MCU: PC が読まずに送信バッファが埋まったら、その周期のサンプルは捨てる（書き込みで止まってウォッチドッグが効かなくなるのを避けるため）。
- PC: `I` で始まり 8 個の値がそろい、有限の数で、`t_ms ≥ 0` の行だけを使う。他は捨てる。
- PC: 1 秒サンプルが来なければ `TimeoutError`。`SerialPlant` は終了時・例外時に必ず `S` を送る。

## 1 step の決め方（`SerialPlant.step(cmd, dt)`）

指令を送り、MCU 時刻で `reset からの累計 dt` に達するサンプルが来るまで読み、その最後の観測を返す。dt を MCU 時刻で積むので、PC 側の遅れで時間軸がずれない。CSV（`LOG_COLUMNS`）は 1 step = 1 行（その step の指令と終わりの観測）。
