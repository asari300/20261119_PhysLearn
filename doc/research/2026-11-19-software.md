## 4. S2R / R2S の手法の現況（教材向け要約）

主な出典: The Reality Gap in Robotics（arXiv 2510.20808, 2025-10）https://arxiv.org/pdf/2510.20808 、Digital Twin Generation from Visual Data（arXiv 2504.13159）https://arxiv.org/html/2504.13159v2 、Real-to-Sim Policy Evaluation（arXiv 2511.04665）https://arxiv.org/html/2511.04665v2 、Real-is-Sim（arXiv 2504.03597）https://arxiv.org/pdf/2504.03597.pdf （いずれも取得 13:3x、検索要約。本文は未読）。2026 年の総説は見つけられなかった（未調査）。

| 手法 | 要点 | 差動 2 輪 + IMU での当てはまり |
|---|---|---|
| Domain randomization (DR) | sim のパラメータ（質量・摩擦・モーター定数・遅れ・センサー雑音）をばらつかせて、どれでも効く制御器を選ぶ | **よく当てはまる**。モーター時定数・ゲインの左右差・ジャイロのバイアスと雑音・制御周期の揺れをばらつかせ、ヨー角速度追従の誤差分布で評価できる。numpy で十分 |
| System identification (SI) | 実機のログから物理パラメータを推定して sim を合わせる。総説は SI を S2R の中心と位置づけ、実機評価を重ねながら同定を繰り返す流れを最近の傾向とする | **最もよく当てはまる**。ステップ指令 → `gz` の応答から 1 次遅れの時定数・定常ゲイン・むだ時間、静止時から `gz` バイアスを最小二乗で求める（計画の R2S そのもの） |
| Real-to-sim（スキャン・映像から sim を作る） | NeRF / 3D Gaussian Splatting で消費者向けの動画から形と見た目を作り、粒子物理などを載せる流れ。カメラ画像で sim を常に補正する例（Real-is-Sim）もある | **ほぼ当てはまらない**。カメラが無く、見た目より動特性が課題なので、ログからの SI で足りる。教材では「大きなロボット・カメラ方策での話」として紹介にとどめる |
| Residual / 学習した残差モデル | 物理モデルで表せない差を学習モデルで足す。総説はパラメータ化が効かないときの手段とする | 小さく試せる。SI 後の残差（例: 床の摩擦、電池電圧の低下）を線形回帰で足す程度なら numpy で可能。データ量が少ないので過学習に注意（推測） |
| 適応（オンライン同定・適応制御） | 走りながらパラメータを推定し直す | バイアスの逐次推定や、ゲインのスケジューリングとして入れられる。後回しの候補 |
