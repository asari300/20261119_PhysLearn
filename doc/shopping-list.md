**代わりを買う前に確かめること:**

- **MG24 Sense**:
  - 今日の CI の `firmware-mg24` が通っているか（`.github/workflows/ci.yml`、落ちても全体は落とさない設定）。通っていなければ、コンパイルが通るようにスケッチを直す作業が先に要る。
  - IMU の電源ピンは PD5 を HIGH にして 300 ms 待つ（Seeed の wiki）。I2C アドレス 0x6A は MG24 では**未確認**。

  - 03 章の配線の D0〜D3 の割り当てが MG24 でも PWM になるか（wiki は 22 ピンすべて PWM 可）。

- どれも、買ったあとにスケッチが動くまで**手戻りの可能性がある**。nRF52840 Sense が 8 個あるうちに、先に買うのが安い。

## 届いたら最初にやること

[doc/bringup.md](bringup.md) を上から。最初の 3 つは次のとおり。

1. **段 0（開封）**: 部品が BOM と合うか。XIAO が **Sense** であること。車輪の直径・トレッド・質量を測る（Robo Base の寸法は未確認なので、ここで初めて分かる）。
2. はんだ付け（ピンヘッダー）。ドライバーは**基板の VM と VCC のそばにコンデンサが載っているか**を見て、**ピン名の印字（シルク）を確かめてから**配線する（03 章 3.2）。
3. **段 1（XIAO 単体）**: 書き込んで `I` 行が流れること。ここで IMU が値を返さなければ mbed 版のボード定義を試す（03 章 3.3）。

モーターをつなぐ前に、段 4 でテスターを使う（電池を入れずに、電池 + と GND の間の導通・VM と VCC が別の線であること）。ストール電流の測定は 03 章 3.2。
