# 10. 次の一歩

## この章でわかること

- この教材の続きに進む道。
- それぞれで、この教材の何がそのまま使えて、何を足すか。

この教材の芯は「sim と実機の差を測って縮める」でした。
どの道に進んでも、この芯はそのまま使えます。
変わるのは、観測と行動の中身と、sim の道具です。

## 道ごとの表

| 次の一歩 | そのまま使えるもの | 足すもの |
|---|---|---|
| エンコーダー | `Plant` の境界、同定の考え方、ログの取り方、安全のゲート | `Obs` に車輪の回転を足す。左右別々に `K`・`τ` を同定できる。位置（オドメトリ）の推定。調査は下の「エンコーダーの調査から」 |
| 無線化（BLE） | `Plant` の境界（`SerialPlant` はシリアルのまま使える）、ログの取り方、安全のゲート | 遅れ・ばらつき・切断・電池の 4 つが一度に増える。調査は下の「無線化の調査から」 |
| カメラ | 境界、ログ、「差」の表の考え方 | 画像の取り込み、時刻合わせ、認識。sim 側には描画（レンダリング）が要る。見た目の差も reality gap になる |
| ROS 2 | `Command`・`Obs` の形（そのままメッセージに写せる）、V-World / R-World の分け方 | ノード・トピック・時刻。sim と実機のトピックを分けて、取り違えを防ぐ（PoC 設計書の注意） |
| MuJoCo → Isaac Sim / Isaac Lab | 同じ `Plant` の境界、同定した数字、ばらつかせ方 | 物理エンジンの設定（接触・摩擦）、車体のモデル（MJCF / USD）。Isaac Sim は GPU が要る。08 章と 90 章 |
| 強化学習 | domain randomization、sim での評価、安全のゲート | 報酬の設計、大量の sim 実行。方策が実機で壊れるのはたいてい reality gap なので、05・06 章の考え方がそのまま効く |
| 模倣学習・VLA | ログの取り方（人の操作も同じ形で記録できる）、境界、安全 | 人の操作のデータ集め、大きなモデル。VLA（Vision-Language-Action）は画像と言葉から行動を出すモデル。出力を実機に流す前のゲートはより大事になる |

## エンコーダーの調査から

出典は `doc/research/2026-11-19-encoder.md`（S048、2026-11-19 17:43〜17:52 JST の取得。スイッチサイエンスのページは 429 で読めず、検索の要約による。**実物では未確認**）。

- **最初の発注には入れない。** 車体（Robo Base）が届いて、取り付け穴と車輪を測ってから、2 回目の発注で決める。
- 入れるなら、手持ちの TT モーターのまま試せる**光センサーの試し部品**（約 480 円。[発注リスト](../shopping-list.md)の案 (C)）。分解能が低く（車輪 1 回転あたり数十カウント）、左右別のゲインとデッドバンドには使えるが、時定数 `τ` には足りない見込み。
- XIAO nRF52840 の **QDEC（回転を数える部品）は 1 系統だけ**（Nordic の製品仕様）。2 輪を QDEC だけで読むことはできないので、2 輪とも GPIO の割り込みで数える設計になる。
- シリアルの取り決めには、エンコーダー用の `E` 行を別に足す（[protocol](../protocol.md) に今は無い）。

## 無線化の調査から

出典は `doc/research/2026-11-19-wireless.md`（S049、2026-11-19 17:44〜17:50 JST の取得。実機では未確認）。

- **最初の 1 周は USB で回す。** 無線は遅れ・ばらつき・切断・電池を一度に足すので、同定が悪いとき、モーターの問題か無線の問題か分けられなくなる。
- 無線化するなら、2 台目の XIAO を「BLE と USB の橋」にする案が次点。PC 側はシリアルのまま変えずに済む。
- **WSL2 から BLE を直接使うのは、第一選択にしない。** 動くまでの段差が多く、この PC では試していない【未確認】。
- XIAO を電池で動かすときも、単3 電池 4 本は DRV8835 のモーター電源だけに使い、XIAO の 5V ピンにはつながない（[09 章](09-safety.md)）。

## 進む前に

- 1 つずつ足してください。2 つ以上を同時に変えると、何が効いたかわからなくなります。
- 足すたびに、「差」の表（01 章）に行が増えます。その行を測る方法も一緒に決めてください。
- 実機に新しいものを流すときは、毎回 09 章のチェックリストに戻ってください。
