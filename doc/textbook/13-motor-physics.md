# 13. sim のパラメータは物理のどこから来るのか

numpy の sim（[4 章](04-sim.md)）は、モーターを「一次遅れ（ゲイン K・時定数 τ）＋デッドバンド」と置いています。
同定（[5 章](05-real2sim.md)）では K と τ を当てはめるだけで、その値が何で決まるかは問いませんでした。
この章では、DC モーターの式から K と τ を導きます。
すると「電池が減ると K はどう動くか」「荷物を積むと τ はどう動くか」が式で言えます。
コードは `src/physlearn/motor.py`、Modelica のモデルは `modelica/` です。

## この章でわかること

- 一次遅れの K と τ が、モーター定数・減速比・電源電圧・慣性からどう決まるか。
- その場旋回で、車体のヨーの慣性がモーターにどう効くか。
- 式からの予測を MuJoCo の物理エンジンで確かめると、どこまで合い、どこがずれるか。
- 電圧と荷物で K・τ がどれだけ動くか。ばらつかせる幅 `SPREAD` への示唆。

## 1. DC モーターの 2 つの式

ブラシつき DC モーターは、電気の式と機械の式の組で書けます。
duty を u（0〜1）、電源電圧を V とします。

電気: `V·u = R·i + L·di/dt + Ke·n·ω`

- 加えた平均電圧が、巻線の抵抗 R の電圧降下、インダクタンス L の電圧、逆起電力に分かれる、という式です。
- ω は車輪の角速度、n は減速比です。モーター軸は車輪の n 倍で回ります。
- 逆起電力はモーター軸の速さに比例します。速く回るほど電流が流れにくくなります。

機械: `J_eff·dω/dt = n·Kt·i − b·ω`

- 電流に比例するトルク（減速して n 倍）が、慣性を加速し、摩擦 b·ω に食われる、という式です。
- J_eff は車輪の軸から見た慣性です（3 節）。
- SI 単位では Kt と Ke は同じ値です。

## 2. L を無視すると一次遅れになる

L は小さく、電流は機械より速く落ち着きます。
L = 0 と置くと電気の式から `i = (V·u − Ke·n·ω)/R` です。
これを機械の式に入れると、次の形になります。

`τ·dω/dt + ω = K·u`

- `K = n·Kt·V / (n²·Kt·Ke + b·R)`（車輪の rad/s per duty）
- `τ = J_eff·R / (n²·Kt·Ke + b·R)`

言葉で言うと次の通りです。

- K は「停動トルク ÷ トルクの落ち方の傾き」です。b が小さければ K は**電圧に比例**します。
- τ は「慣性 ÷ 傾き」です。**慣性に比例**し、電圧には依存しません。
- 減速比 n は両方に効きます。n を上げると、傾き n²·Kt·Ke が増えて τ は短くなります。

`motor.first_order(m, j_eff)` がこの K・τ を返します。
`motor.simulate()` は L を残した 2 つの式をそのまま積分します。

## 3. その場旋回で車体の慣性がどう乗るか

その場旋回では左の車輪が −ω、右の車輪が +ω で回ります。
車輪半径 r、トレッド T とすると、車体のヨー角速度は `Ω = 2·r·ω/T` です。
運動エネルギーを足すと次の通りです。

`½·(2·J_w + I_yaw·(2r/T)²)·ω²`

- J_w は車輪 1 個の自分の軸回りの慣性です。
- I_yaw は車体全体の鉛直軸回りの慣性です。車体の箱、車輪の質量（軸から T/2 の所）、車輪の自分の z 回りの慣性を含みます。

この運動エネルギーを 2 個のモーターで分けるので、1 個が見る慣性は次の通りです。

`J_eff = J_w + I_yaw·2r²/T²`

`motor.yaw_inertia_on_wheel()` がこれです。
車輪が小さく車体が大きいほど、ヨーの慣性が支配的になります。

## 4. デッドバンドと PWM

- **デッドバンド**: 止まった車輪を動かすには、静止摩擦（ギアの摩擦と床の転がり抵抗）を超えるトルクが要ります。停動トルクは u に比例するので、`u > 静止摩擦トルク ÷ (1 duty あたりの停動トルク)` までは回りません。これが sim の `deadband` です。電圧が下がると 1 duty あたりのトルクが減るので、デッドバンドは広がるはずです【未確認・式からの推論】。
- **PWM と平均電圧**: 「平均電圧 = V·u」は近似です。DRV8835 の fast decay では、オフの間にコイルの電流が電源へ戻ります。電流が途切れない条件なら平均電圧はほぼ V·u ですが、電流が途切れる低 duty・高 PWM 周波数では線形からずれます。ドライバーの ON 抵抗による電圧降下もあります。この節は出典で確かめていません【未確認・近似】。

## 5. 数値で確かめる

### 5.1 L を無視してよい範囲

MuJoCo のモデルと同じ定数（5.2 節）で、L を変えて `motor.simulate()` の 63% 時刻を測りました。
一次遅れの τ は 0.0673 s です。

| L/R [s] | 2 階の式の 63% 時刻 [s] |
| --- | --- |
| 0.0001 | 0.0673 |
| 0.001 | 0.0673 |
| 0.005 | 0.0675 |
| 0.02 | 0.0742 |

電気の時定数 L/R が機械の τ の 1/10 を下回れば、差は 1% 以内でした（L/R = 0.0067 s で 0.7%）。L/R が 0.02 s（τ の 0.3 倍）まで大きくなると、10% 延びます。
（S031 で `mujoco_model()` の置き方を直した（R = 1.5 Ω）ので、この表は走らせ直した値です。以前の表の 0.0667・0.0651 は、今の置き方では再現しませんでした。）
小さな DC モーターの L/R は 1 ms 前後と言われますが、車体（Robo Base ミニキット 2WD）のモーターでは確かめていません【未確認】。

### 5.2 式で予測して MuJoCo で確かめる（この章の見せ場）

[`models/diffdrive.xml`](../../src/physlearn/models/diffdrive.xml) のモーターは「トルク = 0.05·u − (0.05/30)·ω」です。
これは 1 節の式で、停動トルク 0.05 N m/duty、傾き 0.05/30 N m s に当たります。
`motor.mujoco_model()` は、xml の質量と寸法から慣性を計算します。

- 車輪（球 0.02 kg、r = 0.03 m）: J_w = 0.4·m·r² = 7.2e-6 kg m²
- 車体の箱（0.25 kg、0.12 × 0.09 m）: I = 4.6875e-4 kg m²
- I_yaw = 箱 + 車輪 2 個 × (m·(T/2)² + J_w) = 5.83e-4 kg m²
- J_eff = 1.122e-4 kg m²（T = 0.10 m）

MuJoCo が読んだ慣性（`model.body_inertia`）は、箱の z が 4.6875e-4、車輪が 7.2e-6 で、手計算と一致しました。
関節の armature と damping はすべて 0 でした。

予測と MuJoCo（duty ±0.5、0.002 s 刻みで記録）の比較です。

| | 定常ヨー角速度 [rad/s] | 63% 時刻 [s] |
| --- | --- | --- |
| 式の予測（一次遅れ） | 9.000 | 0.0673 |
| 2 階の式の数値解（L = 1e-6） | 8.995 | 0.0672 |
| MuJoCo（xml のまま） | 8.978 | 0.0720 |
| 以前の記録（0.01 s 刻み） | 8.98 | 0.080 |

定常値は 0.25% で合いました。
duty 0.05〜0.3 でも定常値は予測と 0.3% 以内で合いました（08 章、S031）。
63% 時刻は MuJoCo が 7% 遅れました。
以前の記録の 0.080 s は 0.01 s 刻みのログで読んだ値で、刻みの分だけ粗い値です。

ずれの原因を、MuJoCo の設定を変えて探しました（1 秒間 duty ±0.5、毎ステップ記録）。

| 設定 | 定常 [rad/s] | 63% 時刻 [s] |
| --- | --- | --- |
| xml のまま（timestep 0.002） | 8.978 | 0.0720 |
| timestep 0.0002 | 8.978 | 0.0702 |
| 接触を硬く（床と車輪の solref を 0.004 1、timestep 0.0005） | 8.997 | 0.0680 |

慣性の数え落としはありませんでした。
ずれの大半は、MuJoCo の接触が柔らかいこと（車輪が床に少し沈み、少し滑る）と、時間刻みの粗さでした。
接触を硬くすると、定常値も 9.0 に近づきました。
なお、床の摩擦係数を 5 にすると 63% 時刻は 0.116 s に延びました。理由は調べていません【未確認】。

### 5.3 Modelica で同じものを書く

[`modelica/DCMotorPivot.mo`](../../modelica/DCMotorPivot.mo) は、Modelica Standard Library 4.1.0 の部品（電圧源・抵抗・インダクター・`RotationalEMF`・慣性・ダンパー）をつないだだけのモデルです。
定数は `motor.mujoco_model()` と同じです。
xml の式は 1 本なので、V・R・Kt・b のうち 2 つしか決まりません。ここでは b = 0、Kt = Ke = 0.05 と置き、傾き Kt²/R = 0.05/30 から R = 1.5 Ω、停動 Kt·V/R = 0.05 から V = 1.5 V としました（S031。それまでは V = R = 1 として b を負の −8.3e-4 で埋めていて、内部抵抗を足すと K が上がるという逆の結果になっていた）。
K・τ は置き方によらないので、上の表の数値は変わりません。電池の内部抵抗は `Rbat` で足せます（演習 3）。
OpenModelica 1.27.2 の `omc` で走らせました（生成物はリポジトリの外に置く）。

```bash
cd <生成物を置く一時ディレクトリ>
MODELICA_DIR=<リポジトリ>/modelica omc <リポジトリ>/modelica/run.mos
```

結果は、ヨー角速度が t = 0.5 s で 8.9946 rad/s、t = 0.0673 s（motor.py の τ）で 5.6875 rad/s でした。
比は 0.632 で、motor.py の定常値・時定数と合いました。

Modelica で書くと嬉しいこと:

- 式を自分で立てずに、部品をつなぐだけで連立方程式ができます。`connect` が「電流の和は 0」「軸の角度は等しい」を書いてくれます。
- 電気と機械を 1 つのモデルに混ぜられます。`RotationalEMF` がその境目です。
- ドライバーの ON 抵抗、電池の内部抵抗、ギアのバックラッシュなどを、部品を足して試せます。

## 6. 電池と荷物で K・τ はどれだけ動くか

### 電圧と K

K は電圧にほぼ比例します（b が小さいとき）。
電池 1 本の電圧は次の値で置きました。出典があるのは公称の 2 つだけです。

| 電源（4 本直列） | 1 本あたり | 合計 | K の比（6.0 V を 1） | 出典 |
| --- | --- | --- | --- | --- |
| アルカリ 新品 | 1.6 V | 6.4 V | 1.067 | Energizer の手引書の**例の式の数字**（仕様値ではない） |
| アルカリ 公称 | 1.5 V | 6.0 V | 1.000 | Energizer E91 のデータシート |
| ニッケル水素 公称 | 1.2 V | 4.8 V | 0.800 | Panasonic BK-3MCC の仕様書 |
| アルカリ 消耗 | 1.1 V | 4.4 V | 0.733 | **出典なし**【推測】（この教材の仮の値） |

出典は `doc/research/2026-11-19-dimensions.md` の「電池の電圧」節（2026-11-19 17:4x 取得。調査による。実物では未確認）です。
同じ節によると、Energizer の手引書（Alkaline Handbook）は、機器が使う電圧の範囲の例を 1 本あたり 1.6 V → 0.9 V、終止電圧を 0.8 V と書いています。
1.1 V はこの範囲の途中の値で、どの資料にも「消耗は 1.1 V」とは書かれていません。

**K の動きの言い方**（15 章の `sag` と同じ基準です）:

- **公称から消耗まで**: 公称 6.0 V（1.5 V × 4）→ 消耗 4.4 V（1.1 V × 4）で **−27%**（4.4 / 6.0 = 0.733）。上は新品 6.4 V で +7%。表の「−27%〜+7%」は、公称を 1 とした幅です。
- **新品から消耗まで**: 新品 6.4 V（1.6 V × 4）→ 消耗 4.4 V で、4.4 / 6.4 = 0.6875 なので**約 −31%**。
- どちらも 1.6 V と 1.1 V の仮の値に基づきます。終止電圧の 0.8 V（4 本で 3.2 V）まで使えば、K は公称の 0.53 倍（−47%）まで下がる計算です。ただし機器はその前に動かなくなるはずで、実際にどこまで使うかは決めていません【未確認】。

`SPREAD["motor_gain"]` の下側（−30%）は、この表の −27% を丸めたものです（下の「SPREAD への提案」）。
電池を替える・消耗まで使う前提なら、下側がこれだけ要ります。

**内部抵抗による電圧降下は表に入っていません。**
Energizer E91 のデータシートの内部抵抗は新品で 1 本 150〜300 mΩ なので、4 本で 0.6〜1.2 Ω です（同じ調査の節）。
表の電圧は電流を流さないときの値で、モーターに電流が流れると下がります。
停動電流の例として Adafruit の TT モーターの実測値 1.5 A（8 節）を使うと、落ちは 0.9〜1.8 V です（調査は「1〜2 V」と丸めています）。
ニッケル水素は約 25 mΩ/本ですが、測り方（1 kHz）が違うので、アルカリと同じ条件の比較ではありません。
2 節の式（b = 0）では K は R に依らず、直列の抵抗を足すと τ だけが (R + Rbat)/R 倍になります【式からの推論】。
5.3 節の Modelica（R = 1.5 Ω）に Rbat = 0.9 Ω を足して omc で走らせると、定常のヨー角速度は 9.0 rad/s のまま、63% 時刻は 0.108 s（約 1.6 倍）でした。
ただし R = 1.5 Ω は xml の式に合わせて決めた値なので、この 1.6 倍は実機の予測ではありません。

### 荷物と τ

車体の箱と同じ形に荷物を均一に載せた、と仮定して計算しました（`motor.mujoco_model()` の J_eff に足す）。

| 荷物 | τ [s] | τ の比 |
| --- | --- | --- |
| なし | 0.0673 | 1.00 |
| +0.05 kg | 0.0774 | 1.15 |
| +0.10 kg | 0.0876 | 1.30 |
| +0.20 kg | 0.1078 | 1.60 |

τ は荷物で長くなる方にしか動かないので、対称な ±30% より「−10%〜+60%」のような非対称な幅の方が物理に合います。

### SPREAD への提案（S041 が採用した）

- `motor_gain`: 電源を固定するなら ±10%。電池の消耗を含めるなら −30%〜+10%。
- `motor_tau`: 載せる荷物の重さから式で決める。0.2 kg まで載せるなら −10%〜+60%。
- K が下がるとデッドバンドが広がるはずなので、両者を独立に振るより、電圧から両方を動かす方が物理に合います（これは採用していない）。

S041 は、この提案（物理から）と、同じ機体の 5 本のログの同定の実測の幅の、広いほうを `randomize.SPREAD` に入れました。
今の値は `motor_gain = (−0.30, +0.14)`、`motor_tau = (−0.14, +0.60)`（比の (下, 上)）で、前の ±0.20・±0.30 は置き換わりました。
この章の表の数字（−27%、+7%）は、その根拠として使われたので、表の電圧の出典を調べ直したあとも変えていません。

## 7. 同定した K・τ から逆にモーターの何が分かるか

- **K** から無負荷回転数が分かります。車輪の無負荷回転数 = K × 1 duty です（デッドバンドと b を無視）。
- **τ** と慣性から、トルクの落ち方の傾き `n²·Kt·Ke/R = J_eff/τ` が分かります（b = 0 のとき。b があると `J_eff/τ = n²·Kt·Ke/R + b`）。
- 両方から停動トルク `= K × J_eff/τ` が分かります（これも b = 0 のとき）。
- J_eff は質量と寸法から計算できます（3 節）。つまり、モーターのデータシートが無くても、車体の質量・寸法と、その場旋回の 1 回のステップ応答から、モーターの停動トルクと無負荷回転数が推定できます。

## 8. 実物のモーター定数

車体（Robo Base ミニキット 2WD。発注リスト `doc/shopping-list.md`）のモーターの無負荷回転数・停動トルク・定格電圧は、確かめていません【未確認】。
MuJoCo のモデルの値（停動 0.05 N m、無負荷 30 rad/s）は「N20 ギアモーター程度」の**仮の値**です。

同じ種類の TT モーター（1:48）の、別の販売元（Adafruit 製品 3777）の公開値が調査にあります（`doc/research/2026-11-19-dimensions.md` の 3 節、2026-11-19 17:44 取得。**参考値**。車体付属のモーターと同じ品かは確かめていません。実物では未確認）。

| | 参考値（Adafruit 3777、6 V） | この章の仮の値 |
| --- | --- | --- |
| 無負荷回転数 | 実測 約 250 rpm = 26.2 rad/s（規格は 200 ± 10% rpm） | 30 rad/s（K = 30） |
| 停動トルク | 0.8 kg·cm = 0.0785 N m | 0.05 N m |
| 停動電流 | 実測 1.5 A | 無し |
| 定格電圧 | 3〜6 V | 6.0 V（公称）〜 6.4 V（新品） |

- 実測の 26.2 rad/s から、K は仮の値（30）より**約 13% 低い**見込みです。規格の下限（200 rpm = 20.9 rad/s）なら約 30% 低くなります。
- τ は同じ桁です（調査は、停動トルクと無負荷回転数から出した傾きで、車体の置き方しだいで 28〜79 ms と見積もっています。この章の 0.0673 s はその中）。
- 停動トルクは参考値のほうが 1.6 倍大きく、仮の値とは合いません。
- 新品アルカリ 4 本の 6.4 V は、定格の上限 6 V を 0.4 V 超えます。
- sim の値はこれで変えていません。実機の K は、下の 1.〜4. で測ってから決めます。

実機で測る方法:

1. 車輪を浮かせて duty 1 で回し、車輪の回転数を測る（無負荷回転数）。
2. その場旋回のステップ応答から K と τ を同定する（[5 章](05-real2sim.md)）。
3. 質量と寸法から J_eff を計算し、7 節の式で停動トルクを出す。
4. 電池の電圧をテスターで測り、K と比べて「1 V あたりの K」を記録する。

## 演習

1. 減速比 n を 2 倍にすると、K と τ はそれぞれ何倍になりますか（b = 0 とする）。`motor.first_order()` で確かめてください。
2. 荷物を車体の中心ではなく前端（x = +0.06 m）に 0.1 kg 載せると、I_yaw はいくつ増えますか。中心に載せた場合と比べてください。
3. `modelica/DCMotorPivot.mo` に電池の内部抵抗（抵抗 1 個）を足し、電流が大きい立ち上がりで K と τ がどう変わるかを omc で確かめてください。
