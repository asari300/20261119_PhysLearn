# 教材の索引

IMU を載せた XIAO と 2 輪車で、Sim2Real (S2R) と Real2Sim (R2S) を学ぶ教材。
コマンドはリポジトリの根で `uv sync` を済ませてから打つ。

## 章の一覧

「実機」は、その章を手を動かして終えるのに部品が要るか。

## 読む順番

- **実機なしコース**（PC だけ）: 00 → 01 → 02 → 04 → 05 → 06 → 07 → 08 → 11（代役で）→ 12 → 13 → 14 → 15 → 16（設計まで）。最後に 10。演習は [解答集](solutions.md) で答え合わせ。動かないときは [つまずき集](../troubleshooting.md)。
- **XIAO 単体コース**（買い物は案 (A)、3,220 円）: 00 → 01 → 02 → 09 → 03 の 3.1（部品のうち XIAO）・3.3 書き込み・3.4 WSL2 で USB・3.5 端末で確かめる（手順 1 と、手順 4 の `hwcheck stream`）・3.6 ログを取る（`still` だけ）・3.7 軸の向き（`hwcheck axes`）→ 11。モーターを使う 3.2 配線・3.9 jog と run は飛ばす。静止ログで雑音とバイアスを測り、05 の同定に使う。手順の練習は先に 12 で。立ち上げ手順書の段 1〜3 がこの範囲。つまずいたら [つまずき集](../troubleshooting.md)。
- **車体込みコース**（案 (B)、7,603 円。電池・テスター込み）: 00 → 01 → 02 → 09 → 03 → 04 → 05 → 06 → 07 → 12（偽の XIAO で練習）→ [../bringup.md](../bringup.md)（立ち上げ。`hwcheck` を段 1〜3 で使う）→ 14 → 15 → 16。注文の前に [発注リスト](../shopping-list.md)。実機のログで R2S、決めたゲインを実機に戻して S2R。つまずいたら [つまずき集](../troubleshooting.md)。
