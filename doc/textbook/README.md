# 教材の索引

IMU を載せた XIAO と 2 輪車で、Sim2Real (S2R) と Real2Sim (R2S) を学ぶ教材。
コマンドはリポジトリの根で `uv sync` を済ませてから打つ。

## 読む順番

- **実機なしコース**（PC だけ）: 00 → 01 → 02 → 04 → 05 → 06 → 07 → 08 → 11（代役で）。最後に 10。
- **XIAO 単体コース**（買い物は案 (A)、約 3,200 円）: 実機なしコースに加えて 09 → 03 の IMU の部分 → 11。静止ログで雑音とバイアスを測り、05 の同定に使う。
- **車体込みコース**（案 (B)、約 7,900 円 ＋ 電池）: 00 → 01 → 02 → 09 → 03 → 04 → 05 → 06 → 07。実機のログで R2S、決めたゲインを実機に戻して S2R。
