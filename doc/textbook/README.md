# 教材の索引

IMU を載せた XIAO と 2 輪車で、Sim2Real (S2R) と Real2Sim (R2S) を学ぶ教材。
コマンドはリポジトリの根で `uv sync` を済ませてから打つ。

## 読む順番

- **実機なしコース**（PC だけ）: 00 → 01 → 02 → 04 → 05 → 06 → 07 → 08 → 11（代役で）→ 12 → 13 → 14 → 15 → 16（設計まで）。最後に 10。
- **XIAO 単体コース**（買い物は案 (A)、約 3,200 円）: 00 → 01 → 02 → 09 → 03 の 3.1（部品のうち XIAO）・3.3 書き込み・3.4 WSL2 で USB・3.5 端末で確かめる・3.6 ログを取る・3.7 軸の向き → 11。モーターを使う 3.2 配線・3.9 jog と run は飛ばす。静止ログで雑音とバイアスを測り、05 の同定に使う。手順の練習は先に 12 で。
- **車体込みコース**（案 (B)、約 7,900 円 ＋ 電池）: 00 → 01 → 02 → 09 → 03 → 04 → 05 → 06 → 07 → 12（偽の XIAO で練習）→ [../bringup.md](../bringup.md)（立ち上げ）→ 14 → 15 → 16。実機のログで R2S、決めたゲインを実機に戻して S2R。
