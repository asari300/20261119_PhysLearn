2. リポジトリの概要（API、14:03 取得）: 説明「an open-source parametric 3D CAD application built in pure Rust. Desktop, web, and automation through MCP.」、homepage `https://solidcraft.io`、スター 17,137、作成 2026-10-07、最終 push 2026-11-19T05:02Z（JST 14:02）。作られて 6 週間ほどの、とても新しく動きの速い道具。
3. **版:** 最新の正式版は **v0.44.1（2026-11-17T19:23Z 公開）**。その後に試験版 v0.45.0-rc.2〜rc.4（rc.4 は 2026-11-19T01:11Z）。研究メモの「v0.22.0 / v0.42.0 の食い違い」は二次資料（smartscope.blog）の古い時点の話で、どちらも今の版ではない。
4. **ライセンス:** README の Licence 節の原文「MIT OR Apache-2.0, at your option.」。リポジトリに `LICENSE-MIT`・`LICENSE-APACHE`・`LICENSE-BRAND` がある。ブランドと UI は `LICENSE-BRAND` で別。（GitHub の API は自動判定で Apache-2.0 とだけ表示するが、README と LICENSE ファイルの方が正。）
5. **入れ方（README の Download 節の原文）:** Windows はインストーラー（MSI。Releases には x64/x86/arm64 の MSI、x64 の `.exe`、portable zip もある）、macOS は dmg（署名・公証あり）、Linux は AppImage か `sudo snap install solidcraft`、Web はブラウザー版 https://solidcraft.io/app （インストール不要）。`.deb`・`.rpm`・Flatpak・FreeBSD もある。
6. **winget:** パッケージ ID は `bherbruck.SolidCraft`（旧名のまま）。`microsoft/winget-pkgs` の 0.44.1 の manifest の InstallerUrl は `github.com/tangency-labs/solidcraft/releases/download/v0.44.1/...msi` を指す（14:05 取得）。出どころは本家と一致。

Until the production certificate is in place, SmartScreen may warn」。研究メモの「署名が無く SmartScreen の警告が出る（未確認）」は**半分正しく半分誤り**: 署名はある（SignPath）が、本番の証明書がまだなので警告が出ることがある。

12. **URDF の質量特性:** `docs/urdf.md` の原文「the mass in kg, the centre of mass and the inertia tensor about it in the link frame, in kg m².
