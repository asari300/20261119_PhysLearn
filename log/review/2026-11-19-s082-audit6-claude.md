- **N-1（06・07 章の「旧い幅に戻すと 68 %…」の説明）**: 数字は再現した（下の表 D2）。ただし「K の下側を −20 → −30 %、τ の上側を +30 → +60 % に広げた」とだけ書き、新しい幅は K の上側を +20 → +14 %、τ の下側を −30 → −14 % に**狭めている**ことを書いていない。「K の幅だけ新しくすると 52 %」は、この狭める分も入っている。使い捨てのスクリプトは本文に無いので、手で再現するには `randomize.SPREAD` を書き換えて `evaluate(Params.load('fixed.json'), 0.2, n=50)` を 4 通りで回す必要がある（自分はこれで 0.68 / 0.52 / 0.64 / 0.42 を得た）。n = 100 だと 72 / 57 / 67 / 50 % なので、n = 50 の数字は ±5 ポイントほど揺れる。
- **N-2（15 章の山場の読み方）**: 「同定しても仕様を外す」は出力から言える。定常偏差 0.373 も、電池が落ち切った K = 8.01 × 0.73 から `5.85 × (0.6 − 0.15) = 2.63`、3 − 2.63 = 0.37 と**自分の計算でも出る**。ただしこの結果は、電池が 13 s の使用で −27 % まで落ち切るという仮定（`SAG_T` = 13 s は仮、−27 % は 13 章の推測の電圧）に乗っている。本文は表で「仮」と書いているが、山場の見出しでは条件が見えにくい。また「制御で吸収する」節の「小さな遅延や向きの差は、tc を緩めて吸収できた」は、出力では「全部入りで電池を新品にしたときだけ tc = 0.3 が OK」（HIDDEN は tc = 0.3 で NG）。遅延や向きの差を分けて tc で吸収できるかは試していない。
