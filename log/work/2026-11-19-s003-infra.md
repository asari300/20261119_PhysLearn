## 依頼

姉妹リポジトリ GlobeMode の作業規約（worktree・ディレクトリ構造・履歴をすべて残すログ）を、最小限に削って移す。成果物は `CLAUDE.md`、セッション記録のフック（`.claude/hooks/save_session_log.py`・`.claude/settings.json`）、start/finish のスキル、`log/` の雛形。Rust・mise・CI・remote・ライセンス規則・スライドの規則は持ち込まない。締めは main への `--no-ff` マージまで。

## 決めたこと

- フックはほぼそのまま移した。変えたのは1点: 出力先と transcript の探し場所を、`git rev-parse --git-common-dir` の親（main のチェックアウト）にした。GlobeMode では finish-session が `--out "$MAIN/log/local"` と `CLAUDE_PROJECT_DIR="$MAIN"` で指していたが、既定でそうなれば手順が短くなり、worktree に `log/local/` を作る間違いも起きない。
- 伏せ字の規則（`REDACTIONS`、WSL の Windows プロファイル名、LAN のアドレス）は削らずに残した。この PC も WSL2 で、削る理由が無い。
- `settings.json` の権限から `cargo *`・`WebFetch(mise.jdx.dev)`・`Read(//tmp/**)`・`python3 -I -` を落とし、`uv run pytest` を足した。フック（Stop は async、SessionEnd は timeout 60）は同じ。
- スキルは start-session と finish-session だけ。`session-docs`・`local-review`・`add-dependency` は移さない（スライドの規則・ライセンス規則を持ち込まないため。レビューの雛形 `log/review/_TEMPLATE.md` は残した）。
- `log/review/README.md` は作らず、書き方を `log/README.md` の review/ の節にまとめた。
- `CLAUDE.md` は 3,692 バイト（GlobeMode は 23,459 バイト。約 1/6）。
