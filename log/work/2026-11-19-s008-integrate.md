同定の実験を 1 つに揃える、安全ゲートの上限をスケッチ (0.6) に合わせる、どの Plant でも同じログを取れるようにする、
静止だけのログで同定が落ちないようにする、MuJoCo を代役にした loop-demo、04〜08 章を実際の出力で直す。

## 決めたこと

- `id_experiment` は指示どおり: 静止 1 s → u = ±0.2, ±0.35, ±0.5（符号交互）各 1 s + 0 を 1 s、計 13 s。`identify` は |u| と符号を分けているので変更不要だった。
- `SafetyGate` の既定 `max_duty` を 0.8 → 0.6（スケッチの `DUTY_MAX`）。
- そのままだと代役 `HIDDEN`（K_yaw = 6、d = 0.2）は 3 rad/s に duty 0.7 が要り、0.6 では届かない。`HIDDEN` を K_m = 20（K_yaw = 8）、d = 0.15 に変えて、要る duty を 0.525 にした。仕様 `SPEC` は変えていない。
- CLI は `sim-log --plant {sim,hidden,mujoco}` にして `--hidden` は消した。`python -m physlearn.mujoco_plant` の自前のログ出力も消して一本化（同定に使えない 1 段ステップだったため）。
- `--plant mujoco` と `loop-demo --real mujoco` は同じ `make_plant` を通す。MuJoCo は雑音 0.05 / 0.005、gz バイアス 0.02（S007 の `--noise` と同じ値）。mujoco は選ばれたときだけ import し、無ければ `uv sync --extra mujoco` と言って終わる。
- 動いたステップが 2 つ未満なら `identify` はバイアスと雑音だけを返す（例外にしない）。`apply` は推定されなかった値を元のまま残す。CLI はその旨を 1 行出す。
- `MujocoPlant.yaw_rate`（雑音なしのジャイロ z）を足し、`control.run` が MuJoCo でも真値で評価するようにした。
