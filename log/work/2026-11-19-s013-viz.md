## 依頼

ログを図にする小さな道具 (`python -m physlearn.plot`) と、教材に貼る図を足す。「sim と実機の差」を目で見えるようにする。matplotlib は任意の依存 `viz`。章の本文と `__init__.py` は触らない。

## 決めたこと

- サブコマンドは `log`（`--params` でモデルを重ねる）・`compare`・`still` の 3 つ。オプションは `--out` と `--params` だけ。
- モデルの重ね描きは `sysid.first_order` を使う（雑音なし。バイアスは足す）。`SimPlant` だと雑音が乗って実ログと区別しにくい。
- 教材の図は CLI にせず `plot.figures(outdir)` にした。公開された関数（`sim_log`・`identify`・`apply`・`tune`・`design`・`run`）を呼ぶだけなので、S008 が入った後は作り直すだけで済む。ゲインの決め方は `loop_demo` と同じ（`tune` → `design`）。
- 静止ログは CLI に作る道が無いので、`figures` の中で代役に指令 0 を 500 step 流して作った。
- 図のタイトルはファイル名だけにした。フルパスを入れると、ホームのパスが PNG に焼き込まれる（実際に一度焼き込まれたので直した）。
- 03 の図はモデルの線を破線にした。実線だと代役の線が完全に隠れた。
