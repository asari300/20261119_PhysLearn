## 03 章との食い違い

- 03 章は `winget install usbipd`。Microsoft の文書は `winget install --interactive --exact dorssel.usbipd-win`（`--interactive` を外すと再起動しうる）。
- 03 章は `usbipd list` を管理者で、と書いていない。文書では `list`・`bind` は管理者の PowerShell、`attach` は不要。
- 03 章は `/dev/ttyACM*` が出なかったときの `cdc_acm` モジュールや、カーネル 5.10.60.1 以上の条件に触れていない。
- 03 章は書き込み時の外れを「もう一度 attach が要ることがある」とだけ書く。手引きでは Windows 側で書き込むのを第一にした。
- Seeed wiki は IMU には mbed 版を勧める。03 章と本スケッチは非 mbed 版。非 mbed 版で `Serial` が通らないときは `#include <Adafruit_TinyUSB.h>` と wiki にある（S005 ではコンパイルが通っているので今は問題ない）。
