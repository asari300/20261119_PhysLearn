## 決めたこと

- 使い方: `uv run python -m physlearn.docs_check [章のファイル ...] [--mujoco]`。引数なしは 04〜08・11〜16 章、`solutions.md`、`README.md`、`doc/bringup.md`。差があれば終了コード 1。`--update` は作らない。pytest には入れない（全部で 23〜37 s。試験は文字列だけを見る速いもの 5 本）。
- 実行は章ごとの一時ディレクトリで、`uv run` を `uv run --quiet --project <根>` に書き換えて `sh` で走らせる。`PYTHONHASHSEED=0`。標準出力と標準エラーを合わせて比べる。
- 比較は 12.2 のとおり（数字は期待の最後の桁の半分 + 1e-9、`...` の行は飛ばす、空行は無視）。符号の `+` は数字の一部として読むので、`+0.52` と `0.52` は同じ扱い（甘い側）。
- 自動で飛ばすもの（印なしで）: `--port`・`fakexiao` を含むコマンド、`pytest`（README の `uv run pytest` が試験を回さないように）、`--extra mujoco`（`--mujoco` が無いとき。表示は「mujoco なし」）。
- 次の 2 つも自動で飛ばす（12.2 に無い追加。章の実物に合わせるため）。(1) 飛ばしたコマンドが書くはずの `.csv`/`.json` を、後ろのコマンドが読むとき（12 章の `sysid real.csv`）。(2) コマンドが `FileNotFoundError` で落ちたとき。章の中に入力ファイルを作る手順が無い所（下の一覧の 05・06）を「差」と数えないため。理由は表に出る。

## 確かめていないこと・残したこと

- 14・15・13 章の出力（表、断片、Modelica）と、08 の `log.csv` の先頭行、本文中の数字は道具で見ていない（上の「諦めた形」）。広げるなら: 15 章は `mismatch one` の出力を行ごとの断片に切って、断片が出力の中に連続して含まれるかを見る形（約 20 行）。14 章は表の数字を取り出す形で、別の仕様が要る。作らなかった。
- 実行は直列。並列にすれば 37 s → 15 s 程度【推測】だが、`--extra mujoco` の `uv run` が同じ環境を同時に書き換えるおそれがあり、作らなかった。
- 比べるのは標準出力 + 標準エラーを合わせたもの。警告が混ざる章が出たら、順序（標準エラーは標準出力のあとにつなぐ）で偽の差が出うる。今の章では出ていない。
- 抜粋（`text`）の比較は、順序つきの部分列。行の途中の省略（`...` が行の途中）は 1 行ぶんの比較を飛ばすだけ。
- 数字の `+` の符号は無視する（`+0.52` と `0.52` が同じ）。符号の抜けを見逃すのは `-` ではなく `+` のときだけ。
- `--mujoco` なしの実行は、mujoco が入っているかを調べない（12.2 の「入っていないとき」ではなく「`--mujoco` が無いとき」で飛ばす）。入っていない環境で `--mujoco` を付けると差が出る。
- 章の `$ ` ブロックの出力に `$ ` で始まる行があると取り違える（今の章には無い）。
