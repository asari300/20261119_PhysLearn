## 決めたこと

- **`SerialPlant` は使わず、pyserial で直接読む。** `SerialPlant` は生の行・`#` 行・MCU の時刻 `t_ms` を外に出さない（`# ERR` は時間切れの例外文にだけ入る）。公開の口だけでは `# ERR`・欠け・飽和が見えないので、`link.BAUD`・`STOP`・`G`・`decode_sample`・`parse_axes` を呼んで自分で読んだ。`link.py` は直していない。そのため見えなかった項目は無い。
- 送るのは起動時の `S` 1 回だけ。`M` を作る口が無い。
- `stream` の基準（出どころを 1 語で付けた）: 周期 10 ± 0.5 ms・欠け 0・壊れた行 0・`# ERR` 0・飽和 0 はスケッチ（`PERIOD_US`、送信バッファが埋まると捨てる、`protocol.md` の飽和 約 ±20 rad/s、`accelRange = 16`）。ジャイロ平均 ±0.02 は `randomize.SPREAD["gyro_bias"]`（gz の値を gx・gy にも当てた。ハードコード）。周期の最大 15 ms・壁時計の最大 50 ms・ノルム ±0.5・ジャイロ標準偏差 0.05 は目安（根拠なし）。
- `axes`: 4 つ目の「手で左に 90°」は入れなかった。3 姿勢の対応が右手系なら gz の符号は自動で合い、動かして確かめるのは bringup 段 5 の `link jog` が既にやるため。
- 姿勢の受け付け: ノルム 9.8 ± 1.0 かつ揺れ 0.3 以内（動いていない）、最大成分が全体の 0.9 以上（傾き約 26° まで。45° で曖昧になるので余裕を持たせた）。どちらも目安（根拠なし）。ダメなら「やり直し」（Enter ありなら同じ姿勢をやり直し、`--no-prompt` なら失敗で終わる）。
- 鏡像（前上と左上の取り違え・裏返し）と、2 つの姿勢で同じ軸に重力が出た場合は断る。

## 申し送り（教材を作り直す担当へ）

- **bringup 段 1**（`I` 行が流れる）: 端末で目視する代わり（または後）に `uv run python -m physlearn.hwcheck stream --port /dev/ttyACM0` を足す。「1 秒に 100 行」「`# ERR` なし」を合否つきで出す。段 1 の合格基準は、このコマンドの MCU 周期・欠け・`# ERR` の行にできる。
- **bringup 段 2**（静止ログ）: `link still` の前に `hwcheck stream` を走らせ、欠けと飽和が 0 であることを先に確かめる。ノルムとジャイロ平均の基準（±0.5 と ±0.02）は `stream` と同じ値なので、段 2 の記述を揃える。
- **bringup 段 3**（軸の向き）: 4 項目を目で見て `--axes` を手で決める手順を、`uv run python -m physlearn.hwcheck axes --port /dev/ttyACM0` に置き換える。出た `--axes ...` の文字列をそのまま以後の `link` に付ける。gz の符号の動的な確認は段 5 の `link jog` に残る。断られたら（鏡像・同じ軸・傾き）は姿勢のやり直し。Enter なしで回したいときは `--no-prompt --settle 5`。
- **03 章 3.7**: 「軸の向きを確かめる」の本文に `hwcheck axes` を足し、4 つの符号の目視は「道具が割り出した結果の確認」に格下げできる。3.5（端末で確かめる）の末尾に `hwcheck stream` を 1 行。
- **12 章（偽の XIAO）**: 「偽物と本物の違い」に、`stream` は偽物で通るが（ジャイロ平均だけ HIDDEN の 0.08 で NG）、`axes` は偽物が水平しか出せないので 1 姿勢目で止まる、と書く。演習に「偽物の `--axes` を変えて `stream` の `az` の符号を見る」を足せる。
- 注意: この道具は `link.SerialPlant` を使わず pyserial で直接開くので、`link` や `fakexiao` が同じポートを開いている間は走らせない。
