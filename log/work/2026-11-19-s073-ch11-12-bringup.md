## 偽の XIAO で走らせた結果（`uv run python -m physlearn.fakexiao` を裏で立て、終わりに止めた）

- `hwcheck stream`: 周期・欠け・`# ERR`・飽和は OK。NG は 2 つ: ジャイロ平均 gz +0.0805（偽物の 0.08）、壁時計の最大 146 ms（基準 50 ms、S050 の 62 ms と違う。走らせるたびに違う）。
- `hwcheck axes --no-prompt --settle 1`: 3 姿勢とも「重力は基板の +z」の後、`NG  2 つ以上の姿勢で重力が基板の同じ軸に出た…`、終了コード 1。依頼文の「1 姿勢目の次で止まる」ではなく、3 姿勢を取り終えてから断られる（S050 の記録と同じ）。
- `link id`: 1700 行、17.9 s。`sysid`: 上の表。
- `link run`（2 回ずつ）: 公称 +3.0 は 0.76 s・8.9 %、0.75 s・9.4 %、-3.0 は 0.91 s・11.2 %、0.89 s・10.8 %（4 つとも NG）。同定後 +3.0 は 0.52 s・1.2 %、0.56 s・1.0 %、-3.0 は 0.54 s・1.5 %、0.55 s・1.4 %（4 つとも OK）。S041 の「+3.0 が NG のまま」は今回の 2 回では再現しなかった（原因は【未確認】のまま）。
- `--axes` の渡し方: `--axes -y,x,z` も `--axes "-y,x,z"` も `expected one argument` で拒まれ、`--axes=-y,x,z` は通る。`x,-z,y` のような `-` で始まらない文字列は空白でも通る。
- 初回に立てた偽物が `link id` の途中で消え（入出力エラー）、立て直した。原因は調べていない（裏で立てたプロセスが他の呼び出しで落ちた可能性）。
