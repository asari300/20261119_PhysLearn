## 依頼

GitHub の公開リポジトリを、何も知らない読者として clone し直し、README と教材のとおりに手を動かして、つまずく所を見つけて直す。直してよいのは入口の文書だけ。コードと章の本文と数値は直さず報告する。

## 決めたこと

- 追体験は、スクラッチ領域に `git clone`（HTTPS、読むだけ）して、README の「最短の道」、実機なしコース（00〜08、11、12、14、15、16）の順に打った。clone の HEAD は a2638b4 で、ローカルの main と同じ。終わったら clone は消した。
- 直すのは入口の文書（README・索引・00 章の「必要なもの」・setup・つまずき集・start-here）だけ。章の本文、試験、記録（`log/review/` など）は触らず、報告に回した。
- 試験の 1 件が素の `uv sync` で落ちる件は、試験の側の直しを統括に任せ、つまずき集に「見つけた」と書くに留めた。

## やったこと

- 素の `uv sync`（`.venv` 61 MB）と `--extra mujoco --extra viz`（220 MB）の両方で、README のコマンドと試験を回した。
- 実機なしコースを順に。章に貼った出力は `docs_check --mujoco` で一致 28・差 0・飛ばした 6。飛ばした 6 件のうち 12 章の端末 2 つの手順と 07 章の実機の経路は、偽の XIAO を立てて（自分の PID だけを止めた）手で打った。16 章の SolidCraft の CLI（v0.44.1）も、出力を clone の外に書いて打った。
- 漏洩の検査（下）。
