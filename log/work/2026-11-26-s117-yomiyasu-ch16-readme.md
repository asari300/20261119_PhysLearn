## 残した表現と理由

- 16 章の「版」（L45、calque の候補）: ソフトウェアの版（バージョン）の意味で、リポジトリ全体と、公式文書の言い方に合わせて使っている。
- 16 章の「正本」（slop_vocabulary の候補）: 上のとおり、他の文書と共通の用語。
- 16 章の trailing_colon（「どこまで確かめたか（…時点）:」）と README の 3 か所（「できる（この PC で確かめた）:」「できない・確かめていない:」「ほかの入口（…）:」）: 後ろの箇条書きの見出し代わりで、句点にすると「できる。」だけの文に読める。
- 16 章と README の太字の多さ（excess_bold）: 未確認・未実行・仮の値を示す太字を残した。確度の印を弱めないため。
- 16 章の「## 演習」（metaphor_label の候補）: 見出しは変えない。
- README L80「車体は、元の Robo Base キット 2WD が…」の読点: 主題のあとに別の主語（「元の … が」）が続くので残した。
- 用語集の「五十音順ではなく、」: 読者が引き方を間違えないための注意で、否定を外すと情報が減る。
